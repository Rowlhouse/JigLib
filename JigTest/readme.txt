Testbed for jiglib - written by Danny Chapman 2005
https://www.rowlhouse.co.uk

JigTest is built along with JigLib from the top-level CMakeLists.txt. The configs/ and data/
folders are found next to the executable if they're there, and otherwise in this source folder,
so a development build runs from anywhere. For a self-contained copy, use

  cmake --install <build folder> --prefix <folder>

Run jigtest on its own to use configs/default.cfg, or give the name of another config:

  jigtest demo1     - demo 1 (full screen)
  jigtest demo2     - demo 2 (full screen)
  jigtest castle    - a castle mesh
  jigtest newton    - Newton's cradle
  jigtest stress    - stress test

You can also give the path to your own config file. Screenshots and program.log are written to
the current folder.

Press H in the demo to show or hide a list of these controls.

Camera:

W A S D            move (hold Shift to go faster)
Q E                move down / up
Right drag         look around
Arrow keys         look around (or drive the selected car)
Alt + left drag    orbit around the selected object (or the last place clicked)
Mouse wheel        move forwards / backwards

Objects:

Left click         select (clicking on nothing clears the selection)
Left drag          pull it around (mouse wheel: nearer / further)
Middle click       throw the object you're dragging
Space              fire the selected object from the camera
Delete             delete the selected object (Backspace works too)
= -                select the next / previous object
X Z N              drop a box, sphere or capsule
/ \                drop a compound object or a ragdoll
C                  drop a car (select it to drive it with the arrow keys)
Ctrl + any of them fire it from the camera instead
M                  first-person character on / off (W A S D to walk, mouse to turn, Space to jump)
T Y                reset / remove all the objects

Simulation:

P O                pause / single step
F G                freezing / shock step on or off
K B V              show contacts / bounding boxes / sleeping objects
Page Up / Down     texture detail
R                  rendering on or off
F1                 save a screenshot as a PNG file
F2                 save a screenshot every few physics steps (see movie_interval in the config)
H                  show / hide the help
Esc                quit

The help is shown at startup unless the config file has "show_help false".

Lots of stuff can be configured by editing configs/default.cfg (or whichever config you use)
with a text editor.

The meshes are in the xml format that is generated by the Ogre3D plugin for the free-to-use
DeleD editor.

Notes on the jigtest code:

"framework" stuff, that could be lifted out and put into any jiglib
project, lives in framework. Probably end up in JigUtilsLib one day...

"application" stuff lives in application.

Building jiglib requires just standard C++. The test framework requires OpenGL, SDL3,
stb_image and pugixml. The build uses SDL3 and pugixml if they're installed, and otherwise
downloads them.
